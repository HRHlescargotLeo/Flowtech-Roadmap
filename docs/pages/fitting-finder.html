What we're proposing

Four questions that narrow 13,000 push-in fittings to a handful: tube size, what it connects, thread (only if it screws into a port) and shape. Each answer shows how many products it leaves. Beside it, a box for another maker's part number that returns what Flowtech stocks to do the same job.

Why

There is no guided route into the range today. A maintenance engineer with an 8mm tee in their hand either knows the code or filters a 13,159-product listing. Code search already works well for Flowtech's own and stocked brands' codes (searching SMC's KQ2T08-00A goes straight to the product), so equivalents are the natural next step, and the one that moves sales toward FT Pro.

Equivalents here are a sample mapping. In the build they would come from Flowtech's cross-reference data in Pimberly.
